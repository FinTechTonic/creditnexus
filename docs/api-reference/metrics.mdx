# Metrics API

## Prometheus Metrics Endpoint

CreditNexus exposes Prometheus-compatible metrics at the `/metrics` endpoint for monitoring, alerting, and observability.

**GET** `/metrics`

Returns Prometheus metrics in text format.

### Query Parameters

- `format` (optional): Output format
  - `"prometheus"` (default): Prometheus text format
  - `"openmetrics"`: OpenMetrics format (RFC 8428)

### Response

- **Status Code**: 200
- **Content-Type**: 
  - `text/plain; version=0.0.4; charset=utf-8` (Prometheus format)
  - `application/openmetrics-text; version=1.0.0; charset=utf-8` (OpenMetrics format)
- **Body**: Prometheus metrics in text format

### Example

```bash
# Get metrics in Prometheus format (default)
curl http://localhost:8000/metrics

# Get metrics in OpenMetrics format
curl http://localhost:8000/metrics?format=openmetrics
```

### Example Response

```
# HELP creditnexus_http_requests_total Total HTTP requests
# TYPE creditnexus_http_requests_total counter
creditnexus_http_requests_total{method="GET",endpoint="/api/health",status_code="200"} 42.0

# HELP creditnexus_http_request_duration_seconds HTTP request duration in seconds
# TYPE creditnexus_http_request_duration_seconds histogram
creditnexus_http_request_duration_seconds_bucket{method="GET",endpoint="/api/health",le="0.005"} 10.0
creditnexus_http_request_duration_seconds_bucket{method="GET",endpoint="/api/health",le="0.01"} 25.0
...
```

## Available Metrics

### HTTP Request Metrics

- **`creditnexus_http_requests_total`** (Counter)
  - Total HTTP requests by method, endpoint, and status code
  - Labels: `method`, `endpoint`, `status_code`

- **`creditnexus_http_request_duration_seconds`** (Histogram)
  - HTTP request duration in seconds
  - Labels: `method`, `endpoint`
  - Buckets: 0.005, 0.01, 0.025, 0.05, 0.1, 0.25, 0.5, 1.0, 2.5, 5.0, 10.0

### LLM Call Metrics

- **`creditnexus_llm_calls_total`** (Counter)
  - Total LLM API calls by provider, model, and status
  - Labels: `provider`, `model`, `status` (success, error, rate_limited)

- **`creditnexus_llm_call_duration_seconds`** (Histogram)
  - LLM call duration in seconds
  - Labels: `provider`, `model`
  - Buckets: 0.1, 0.5, 1.0, 2.0, 5.0, 10.0, 30.0, 60.0

- **`creditnexus_llm_tokens_total`** (Counter)
  - Total LLM tokens (input + output)
  - Labels: `provider`, `model`, `type` (input, output)

- **`creditnexus_llm_cost_total`** (Counter)
  - Total LLM cost in USD
  - Labels: `provider`, `model`

### Policy Decision Metrics

- **`creditnexus_policy_decisions_total`** (Counter)
  - Total policy decisions by decision type and rule
  - Labels: `decision` (ALLOW, BLOCK, FLAG), `rule_applied`

- **`creditnexus_policy_decision_duration_seconds`** (Histogram)
  - Policy decision duration in seconds
  - Labels: `decision`
  - Buckets: 0.001, 0.005, 0.01, 0.025, 0.05, 0.1, 0.25, 0.5

### Document Processing Metrics

- **`creditnexus_documents_processed_total`** (Counter)
  - Total documents processed by status and type
  - Labels: `status` (success, error), `type` (pdf, docx, image, text)

- **`creditnexus_document_processing_duration_seconds`** (Histogram)
  - Document processing duration in seconds
  - Labels: `type`
  - Buckets: 1.0, 5.0, 10.0, 30.0, 60.0, 120.0, 300.0

### Trade Execution Metrics

- **`creditnexus_trades_executed_total`** (Counter)
  - Total trades executed by status and type
  - Labels: `status` (success, failed), `type` (buy, sell)

- **`creditnexus_trade_value_total`** (Counter)
  - Total trade value in USD
  - Labels: `type`

### Verification Metrics

- **`creditnexus_verifications_total`** (Counter)
  - Total verifications performed by status and type
  - Labels: `status` (success, failed), `type` (satellite, ground_truth)

- **`creditnexus_verification_duration_seconds`** (Histogram)
  - Verification duration in seconds
  - Labels: `type`
  - Buckets: 1.0, 5.0, 10.0, 30.0, 60.0, 120.0, 300.0

### Stock Prediction Metrics

- **`creditnexus_stock_predictions_total`** (Counter)
  - Total stock predictions generated by timeframe and status
  - Labels: `timeframe` (daily, hourly, 15min), `status` (success, error)

- **`creditnexus_stock_prediction_duration_seconds`** (Histogram)
  - Stock prediction duration in seconds
  - Labels: `timeframe`
  - Buckets: 0.5, 1.0, 2.0, 5.0, 10.0, 30.0, 60.0

- **`creditnexus_stock_prediction_gpu_memory_bytes`** (Histogram)
  - GPU memory used for stock predictions
  - Labels: `timeframe`
  - Buckets: 100MB, 500MB, 1GB, 2GB, 5GB

### Database Metrics

- **`creditnexus_db_connections_active`** (Gauge)
  - Active database connections by state
  - Labels: `state` (idle, in_use)

- **`creditnexus_db_connections_total`** (Counter)
  - Total database connections by action
  - Labels: `action` (created, closed)

- **`creditnexus_db_query_duration_seconds`** (Histogram)
  - Database query duration in seconds
  - Labels: `operation` (select, insert, update, delete)
  - Buckets: 0.001, 0.005, 0.01, 0.025, 0.05, 0.1, 0.25, 0.5, 1.0

### System Metrics (Optional)

Requires `psutil` and `SYSTEM_METRICS_ENABLED=true`:

- **`creditnexus_system_cpu_percent`** (Gauge)
  - System CPU usage percentage
  - Labels: `cpu` (total, core_0, core_1, ...)

- **`creditnexus_system_memory_bytes`** (Gauge)
  - System memory usage in bytes
  - Labels: `type` (total, available, used, free)

- **`creditnexus_system_disk_bytes`** (Gauge)
  - System disk usage in bytes
  - Labels: `type` (total, used, free), `mount` (e.g., "/", "C:\\")

### Application Info

- **`creditnexus_app`** (Info)
  - Application information
  - Labels: `version`, `environment`

## Configuration

Metrics can be configured via environment variables:

- `METRICS_ENABLED` (default: `true`): Enable Prometheus metrics
- `METRICS_PATH` (default: `/metrics`): Metrics endpoint path
- `SYSTEM_METRICS_ENABLED` (default: `false`): Enable system metrics (requires psutil)
- `METRICS_COLLECT_INTERVAL` (default: `60`): System metrics collection interval in seconds

## Prometheus Scraping

To scrape metrics with Prometheus, add the following to your `prometheus.yml`:

```yaml
scrape_configs:
  - job_name: 'creditnexus'
    scrape_interval: 15s
    metrics_path: '/metrics'
    static_configs:
      - targets: ['localhost:8000']
```

## Grafana Dashboards

You can create Grafana dashboards using the exposed metrics. Example queries:

- **Request Rate**: `rate(creditnexus_http_requests_total[5m])`
- **Error Rate**: `rate(creditnexus_http_requests_total{status_code=~"5.."}[5m])`
- **P95 Latency**: `histogram_quantile(0.95, rate(creditnexus_http_request_duration_seconds_bucket[5m]))`
- **LLM Cost**: `sum(rate(creditnexus_llm_cost_total[1h]))`
- **Database Connections**: `creditnexus_db_connections_active`

## Best Practices

1. **Label Cardinality**: Avoid high-cardinality labels (e.g., user_id, deal_id). Use aggregation instead.
2. **Metric Names**: Follow Prometheus naming conventions (snake_case, descriptive).
3. **Histogram Buckets**: Choose buckets appropriate for your use case.
4. **Scraping Interval**: Use 15-30 second intervals for most metrics.
5. **Retention**: Configure Prometheus retention based on your needs.

## Troubleshooting

### Metrics Not Appearing

1. Check that `METRICS_ENABLED=true` in your environment
2. Verify the `/metrics` endpoint is accessible
3. Check application logs for metrics initialization errors

### High Cardinality Warnings

If you see warnings about high cardinality:
- Review metric labels and remove high-cardinality dimensions
- Use aggregation (e.g., `user_id` → `role`, `organization_id`)

### System Metrics Not Available

If system metrics are missing:
1. Install `psutil`: `pip install psutil`
2. Set `SYSTEM_METRICS_ENABLED=true`
3. Restart the application
